# 第 99 篇验证记录

验证日期：2026-09-10。环境：PostgreSQL 16.14（Homebrew），隔离临时集群，仅开放本地 Unix socket。测试结束自动停库、清理，不连接已有数据库。

## 通过项目

- 直接执行文章中标记的 SQL，测试代码不另抄一套待验证 SQL。
- CHECK 添加后 `convalidated=false`，新违规数据被拒绝；验证后变为 true。
- 外键、NOT NULL 兼容方案和并发唯一索引挂约束均可执行，违规新数据被拒绝。
- 加列与单独设置 volatile 默认值后，旧行仍为空，新行取得默认值。
- UPDATE 依次处理 5000、5000、1、0 行，筛选范围外记录不变。
- DELETE 依次处理 10000、10000、1、0 行，截止时间外的两条记录保留。
- 运行文章中的 Bash 驱动脚本，第四批返回 0 后正常退出。
- 三个真实会话复现锁队列：长事务持读锁，DDL 等待强锁，新 SELECT 被排队的 DDL 阻塞。DDL 等锁超时后，新 SELECT 完成，而第一个事务尚未结束。

## 复现

在仓库根目录执行，`--pg-bin` 指向安装了 initdb、pg_ctl、psql 的目录；不要以 root 运行：

```bash
python3 maintenance/test_online_changes.py --pg-bin /path/to/postgresql/bin
```

测试脚本自行创建数据库集群，不接受业务库连接串。仅使用测试数据，文件写入系统临时目录。
