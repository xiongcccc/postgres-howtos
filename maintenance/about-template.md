# 关于 PostgreSQL Howto

PostgreSQL Howto 中文版面向 DBA、DBRE、后端和基础设施工程师，围绕实际问题组织 PostgreSQL 知识。除了快速查找一个错误或参数，也希望帮助读者理解操作背后的机制与取舍。

## 来源与维护

项目源自 Nikolay Samokhvalov（[@NikolayS](https://twitter.com/samokhvalov)）于 2023-09-26 发起的 [PostgreSQL Howtos](https://gitlab.com/postgres-ai/postgresql-consulting/postgres-howtos)。

> Postgres docs are awesome but often lack practical pieces of advice (howtos).

中文版保留上游原文与作者信息，也持续整理个人实践、社区会议和优质技术博客。文章的系列与来源分别记录；本地实测、文档核对和外部案例不会混写。技术材料与图片的版权及许可沿用各自原始声明，不因本站收录而改变。

中文翻译、解读与技术校订：**xiongcc**。一名 PostgreSQL / Greenplum 工程师、开源项目维护者和技术写作者，公众号为 **PostgreSQL 学徒**。

## 参与改进

发现翻译、SQL、版本适用性或页面问题，欢迎在 [项目 Issues](https://github.com/xiongcccc/postgres-howto/issues) 提出，也可以直接修改源文件发起 Pull Request。请附上文章链接、PostgreSQL 版本和能够说明问题的最小例子；分享实际生产信息前，请先移除账号、连接信息和业务数据。

文章讨论仍保存在 [原评论仓库](https://github.com/xiongcccc/gitalk-comment/issues)，文章末尾保留对应的查找入口。
