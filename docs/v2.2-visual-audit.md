# V2.2 视觉审计

日期：2026-10-24。基线：`cfc4708`，展示实现为 `20eece6`。保留 Docsify、静态文章、现有内容和路由，本轮只精修品牌与展示层。

## 实际证据

已使用独立 Chrome 保存 [桌面首页](v2.2/before/home-desktop-light.png)、[手机首页](v2.2/before/home-mobile-light.png)、[深色首页](v2.2/before/home-desktop-dark.png)、[专题](v2.2/before/topics-light.png)、[学习路径](v2.2/before/paths-light.png)、[长文](v2.2/before/long-article-light.png)、[代码](v2.2/before/explain-light.png)、[搜索](v2.2/before/search-light.png)与 [页头](v2.2/before/header-mobile-dark.png)。六种宽度、两种主题的基线没有页面横向溢出或页头重叠，不能把这些写成已有故障。

[基线记录](v2.2/before/metrics.json)中，首页正文与页头共有 26 个装饰性箭头。现有 favicon 实测为 64×64 PNG，带白底；大图原件为 1706×1324。问题不是原插画没有大图，而是插画内容、白色底框与细节不适合作为小尺寸界面标识。

## 已确认的问题

| 优先级 | 页面与元素 | 证据与设计原因 | 处理方式 |
| --- | --- | --- | --- |
| P0 | 首页问题、专题、路径、Section 链接与 GitHub 导航 | 26 个箭头重复表达普通跳转，没有提供额外信息，抢占条目尾部空间 | 在生成器和模板中移除，不使用 CSS 隐藏；保留真正的折叠状态及前后阅读方向 |
| P0 | 页头、favicon 与分享图 | 小插画保留大量细节和白底；暗色页头中白色方块突出；不同入口没有独立品牌系统 | 原创单路径矢量标识、统一明暗版本、小尺寸图标与分享资源 |
| P1 | 首页专题与学习路径 | 编号、标题、计数、描述和箭头形成四五列；专题编号并不代表学习顺序 | 去掉条目编号，把标题/说明与右侧数量组成两列；路径内有意义的文章步骤不变 |
| P1 | 首页 Section 标题 | EXPLORE、LEARN、LATEST、ABOUT THE PROJECT 与中文标题反复组成双层标题 | 删除不提供信息的英文标签，使用中文标题、统一间距与轻量文字入口 |
| P1 | SQL / EXPLAIN 字体回退 | 首轮截图复核后，通过 Chrome CSS.getPlatformFontsForNode 确认当前 Mac 上实际落到 Courier；原栈遗漏 ui-monospace 与 Menlo | 保留 JetBrains Mono 优先级，补齐系统等宽回退，不新增网络字体；再次核对代码、字符保真与局部滚动 |

## 可改进而非功能故障

- 页头图标、字标与移动端左右边距可以更紧凑、统一，不需要增加 Header 高度。
- 问题条目的点击区域已足够，但移除箭头后需保留可辨认的链接反馈，不能变成看不出可点击的正文。
- 专题、路径与最近收录需要统一基线、轻量分隔线和数量字号，避免每块模块都有不同的视觉语法。
- 侧栏默认折叠、当前专题展开和状态记忆已正常；只减轻分隔线和非当前条目的强调，不重写其交互。
- 正文 840px 上限、16px 中文字号、代码局部滚动与明暗色已正常；阅读页应沿用新品牌并精修工具与目录，不改变技术原文。

## 原待验证的项目与结论

以下最初是验收任务，不是已经复现的故障：新标识的高分屏表现、替换后的页头宽度、去除编号后的布局、静态页面资源哈希、移动目录与表格、焦点和 reduced motion。实际检查已覆盖六种宽度、两种主题、1x/2x 符号渲染、全部旧文章和静态阅读，结果见交付报告。

最终结果与限制在 [交付报告](v2.2-visual-report.md)中记录，不以浏览器可渲染推断真实 Safari、搜索引擎收录或现场性能数据。
