## 确认的问题

### P0

在上述范围未发现阻断整站阅读、历史 URL 失效或章节刷新偏移。不能据此断言所有设备、浏览器和网络条件均无问题。

### P1：手机图片预览不能查看细节

`#/docs/42` 的锁树原图为 1409×565px。390px 手机正文约显示 350px 宽，点击图片后只剩约 324px 宽，原先只有关闭按钮，没有原始尺寸切换；文字细节并没有被放大。1440px 桌面预览约 1166px 宽，仍不能查看完整原始尺寸。

原因是预览图片同时受到 `max-width:100%` 和最大高度约束，组件只实现了适应窗口，没有提供局部平移的原始尺寸状态。

最小修复：保留默认适应窗口，增加一个原始尺寸 / 适应窗口图标按钮，原始图片在弹窗内滚动，工具栏不随图片滚动。保留原图比例、颜色、Esc、关闭按钮、背景点击和焦点返回。不改变正文或图片资源。

证据：`visual-qa/v2.2.1/before/image-viewer-390-dark.png`、`before/image-metrics.json`。修复后的数值和截图见精修报告。

### P2：复制按钮焦点边框被裁切

复制按钮占满工具栏高度，代码容器 `overflow:hidden`，全局焦点边框向外偏移 3px。键盘聚焦时，顶部及右侧的轮廓被容器裁掉，焦点形状不完整。

最小修复：仅对代码工具栏按钮和可聚焦代码区域使用内侧焦点边框。保持 44px 按钮、现有颜色和圆角，不改其他组件的全局焦点规则。

证据：`visual-qa/v2.2.1/before/code-focus.png`。

### P2：部分搜索摘要仍显示实体编码

`work_mem` 检索的部分摘要显示字面的 `&quot;`。检索和跳转正常，但摘要不够自然。本轮记录而未扩大修复：全文索引由 Markdown 词法 token 提取，不能把代码中的实体字面量与普通段落统一解码。需要独立处理解析语义并增加代码保真测试，不采用在结果 DOM 中直接解析 HTML 的快捷修复。
