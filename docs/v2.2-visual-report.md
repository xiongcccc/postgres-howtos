# PostgreSQL Howto V2.2 视觉精修报告

日期：2026-10-24。基线：`cfc4708`，改版提交：`3b907f9`。本报告记录实现、本地验收与部署完成后的正式站复核；生产结果单独列出。本轮没有迁移框架，也没有增加网站运行时依赖。

本地预览：[首页](http://127.0.0.1:4176/#/README) · [专题](http://127.0.0.1:4176/#/docs/topics) · [学习路径](http://127.0.0.1:4176/#/docs/paths) · [静态文章](http://127.0.0.1:4176/articles/105/)。

## 设计取舍

保留首页信息架构、白色与中性深色底、深蓝品牌色及少量青绿交互。此次变化来自删除冗余信息、重新分配文字权重与统一空间关系，不靠新卡片、渐变、阴影或进入动画制造变化。

### 箭头只表达真实方向与状态

- 基线首页正文和页头实测有 26 个装饰性箭头，修改后两种主题均为 0。普通跳转入口不再携带箭头，包含 GitHub 顶部导航、问题入口、专题、学习路径及 Section 的“全部”链接。
- 在首页模板和目录生成器中真正删除对应标记，没有用 CSS 隐藏，也没有机械替换文章中的箭头字符。
- 保留侧栏与目录展开状态的 chevron；文末同专题上一篇/下一篇使用仓库已有 Lucide 左右箭头，它们有明确的阅读方向含义。
- 普通入口通过文字、下划线、轻量分隔线、Hover 与 Focus 表明交互，不让箭头成为判断可点击性的唯一线索。

### 一套原创品牌

先比较原创几何大象与独立字母标识：[实际方向比较](v2.2/design/logo-directions.png)。最终采用“折页 H”：Howto 首字母的单路径几何轮廓，右上角切角关联文档，不叠加大象、数据库圆柱、代码括号等符号。

大象方向在小尺寸下需要依赖更多细线，也容易混淆官方身份；只保留为设计过程截图，没有在站点中留下第二套可切换 Logo。新图形不是 Slonik 的重绘，不宣称获得 PostgreSQL 官方背书。商标边界与参考来源见 [视觉审计](v2.2-visual-audit.md)。

符号没有细线、嵌入位图或字体依赖。完整 SVG 与分享图的文字保留可编辑性，缺少 Inter / Noto Sans SC 时采用系统字体，不请求外部字体服务。网站页头保留可访问的真实 HTML 字标，与符号组成同一套标识。

新资源使用新路径，并由现有构建为 SVG、PNG、Apple 图标及 OG 图片添加内容哈希，避免继续命中旧图标。静态文章、静态目录和 Docsify 页头一起更新。旧插画仍保留在仓库，不破坏历史引用。

### 首页、专题与路径

- 删除 Hero 上方重复的英文说明，以及 EXPLORE、LEARN、LATEST、ABOUT THE PROJECT。中文标题成为各区块唯一主标题。
- 保留 PostgreSQL Howto 与原副标题。桌面 H1 为 42px、手机 32px，字距为 0；没有扩大成营销页。
- 专题移除 01–09 与尾部箭头，从四列元素收敛为“标题/说明 + 收录数量”两列。数量不拆行，标题优先；桌面三列、平板两列、窄手机一列。
- 路径入口采用同一套两列语法，不再给没有先后关系的六条路线编号；路径内部文章的有序步骤全部保留。
- 学习路径详情将文章数与标题基线对齐，减轻边框，保留目标、场景和完整文章顺序。
- 最近收录用更明确的标题字重与行间距，日期采用等宽数字，专题/系列/来源为次级文字。手机中日期置于标题之前，长标题自然换行。
- 首页统计继续由元数据生成，仍为 108 篇技术文章、9 个专题与 6 条路径；主归属与跨专题口径不变。

### 页头与阅读工具

- 页头仍为 64px，统一图标与字标间距，删除 GitHub 后的装饰箭头和工具区多余的竖分隔线。手机收紧侧边距、符号与字标，360px 下不挤占搜索和主题按钮。
- 侧栏删除每个专题之间反复出现的分隔线，减轻非当前项；当前文章增加细边线，保留主专题展开、手动状态和必要定位。
- 正文沿用已验证的 840px 上限、16px 字号和 1.85 行高，不为视觉变化再次改宽度。代码工具使用较小图标但保留 44px 点击区，复制内容不变。
- 截图复核和 Chrome 实际字体查询确认当前 Mac 的代码回退原先落到 Courier，随后补齐 `ui-monospace` 与 Menlo，保留 JetBrains Mono 优先级；最终两种主题实测使用 Menlo。无需下载字体，执行计划仍严格等宽、不折行；实际字体记录附在视觉专项中。
- TOC 仅当前章节显示强调线，其余不再累积装饰竖线；保留多级目录、Sticky、手机折叠和长标题换行。
- 增加少量共享的字号与轻分隔线 token；没有引入另一套 CSS 体系。明暗主题保持一致布局，深色符号使用浅蓝，不对旧图标做滤镜变色。
- 补齐 V2.1 报告中记录的 reduced motion 限制：旧 Hash 页跳过 Docsify 的 500ms 锚点动画，采用即时定位；普通模式保持原行为，静态页继续使用原生锚点。

## 验证结果

使用仓库现有 Playwright 和本机独立 Chrome，屏蔽访问统计，不使用个人账号。覆盖 1440、1280、1024、768、390、360px，两种主题；Logo 额外检查 16、24、32、48、64px 及 deviceScaleFactor 1/2。2x 是浏览器模拟，不等于所有真实高分屏设备均已测过。

- 目录构建、125 个生成文件一致性、24 项 Node 测试通过。新增品牌几何、SVG/PNG 摘要、输出尺寸、箭头语义与品牌引用测试。
- 旧站完整回归通过：全部 109 篇路由、中文标题、署名、专题/路径入口、搜索与历史状态、抽屉、图片放大、弹窗焦点、代码复制。
- V2.1 专项通过：109 篇静态文章在禁用 JavaScript 时可阅读，650 个 fenced code block 逐字符一致，canonical、静态目录、真实 404、九组检索、二维码图片加载与目录刷新正常。
- V2.2 视觉专项通过：两种主题中装饰箭头从 26 减到 0；各断点页头品牌与工具不重叠；实际 SVG、Apple 图标与社交图返回 200；符号像素检查排除空白、整块背景等错误。
- reduced motion 下的目录点击与刷新均正确定位，记录到的 Docsify JavaScript 滚动调用为 0。普通模式的目录与刷新同时通过原有回归。
- 真实截图已人工复核。首轮后调整截图等待时间，避免把瞬时加载进度条当成最终页头边框，并统一品牌尺寸对比图的标签基线；没有凭一轮 CSS 或构建成功宣布视觉验收。
- `git diff --check` 通过。编号文章 Markdown、`data/articles.json`、全文索引、来源、License、Sitemap 和历史路径没有修改；静态 HTML 是模板与资源摘要更新后的生成结果。

主要记录：[视觉专项](v2.2/after/metrics.json)、[旧路由回归](v2.2/after/legacy-metrics.json)、[静态阅读回归](v2.2/after/static-metrics.json)。命令与环境变量见 [维护说明](../maintenance/CATALOG.md)。品牌源与导出流程见 [品牌维护说明](../images/brand/README.md)。

两份 CSS 合计 33,058 字节；单个符号 SVG 为 134 字节，SVG favicon 为 208 字节。新的品牌位图只用于 favicon 回退、Apple 主屏幕和分享预览，不把 1200×630 分享图加载进首页正文。无新增外部字体或客户端库。

本地无 CPU/网络限速、1440/390px、内容出现后观察 1 秒的单次实验室记录：首页 LCP 均为 116ms、CLS 为 0；静态逻辑复制文章 LCP 为 100ms、CLS 约 0.0102。它们只作为回归线索，不代表公网、真机或真实用户 Core Web Vitals。

## 维护与边界

- 正式域名的 HTTP 与浏览器验收已通过；社交平台已有的分享图缓存仍不能由站点资源更新或本地验证保证刷新。
- 真机 Safari、微信浏览器、真实弱网与搜索引擎实际收录未覆盖，不作全平台或完整 WCAG 认证。
- 完整 SVG 的文本字标采用字体回退，不承诺不同系统字体逐像素一致；核心符号是纯路径，比例与识别不依赖字体。
- Docsify 仍固定为 4.13.1。升级时需回归 `$resetEvents` 生命周期、普通锚点和 reduced motion 分支，不修改第三方压缩库。
- 技术图片和二维码保留原文件；真实加载不等于能够保证远程图片长期存在或群码仍然有效。
